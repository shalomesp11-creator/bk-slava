# Перевірка першої робочої версії

Перевірено 1 жовтня 2026 року.

- TypeScript: `bun run typecheck` без помилок.
- Локальні 12 сторінок на ширинах 1440 та 390 px: 24 успішні відповіді, жодного горизонтального переповнення, жодного несправного зображення та помилки JavaScript.
- Перевірено валідацію форми, стан підготовленого звернення, згоду, закриття через Escape, повідомлення Telegram, категорії портфоліо, діалог проєкту та клавіатурне керування до/після.
- Вступне відео реально відтворюється в браузері: desktop 1920 px, mobile 960 px, обидва файли 46 секунд. Кнопка пропуску працює, повторний перегляд у поточній сесії не запускається.
- Reduced motion: повний статичний сайт, вступне відео не створюється та не завантажується.
- Desktop та mobile перевірено на локальних повних знімках екрана. Виправлено пропорції фотографій.
- Новий GitHub-репозиторій: `shalomesp11-creator/bk-slava`, приватний.
- Production-збірка `bun run build` успішна. Node-адаптер віддає головну, послуги, портфоліо та відео без авторизації; перевірено HTTP 200. Додано byte ranges для MP4.

Higgsfield повідомляє про успішне розгортання, але анонімні HTTP-запити заблоковані платформою (401). Railway повідомляє, що пробний період завершено. Для зовнішнього показу використовується тимчасовий Cloudflare Tunnel до перевіреної локальної production-збірки; це не постійний хостинг.

Зовнішнє посилання `https://hat-gbp-transition-entering.trycloudflare.com`: перевірено HTTP 200 для головної, демонтажу, портфоліо та мобільного відео без авторизації.

Форма не надсилає дані автоматично. Telegram username ще відсутній. Портфоліо містить позначені візуалізації. Десять написаних прикладів відгуків збережені для погодження та не представлені як справжні свідчення клієнтів.
