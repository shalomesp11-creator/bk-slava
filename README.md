# ТОВ БК Слава

Багатосторінковий український сайт будівельно-ремонтної компанії, яка працює з 2006 року у Києві та Київській області.

## Перегляд

Готова локальна production-версія: http://127.0.0.1:8080. Тимчасове зовнішнє посилання для показу замовнику надається окремо; воно діє, поки працюють локальний сервер і тунель.

Поточний перегляд: https://hat-gbp-transition-entering.trycloudflare.com

Higgsfield-версію розгорнуто, але хостинг повертає зовнішнім відвідувачам `401 unauthenticated`. Railway у наявному акаунті повідомив про завершення пробного періоду; платний план не оформлювався.

## Локальний запуск

Потрібні Node.js 22+ та Bun. З кореня репозиторію:

```sh
cd app
bun install --frozen-lockfile
bun run dev --host 127.0.0.1 --port 3000
```

Відкрити http://127.0.0.1:3000. Команда `bun run build` перевіряє TypeScript і створює серверну та клієнтську збірки у `app/dist`. `bun run start` запускає цю готову збірку на порту 8080. Для власного домену встановіть `VITE_SITE_ORIGIN` під час збірки та `SITE_ORIGIN` під час запуску. Є Dockerfile та конфігурація Railway для майбутнього постійного хостингу.

## Склад

- Головна, каталог та шість повноцінних сторінок послуг.
- Портфоліо з категоріями, деталями проєктів і доступним з клавіатури порівнянням до/після.
- Компанія, контакти, політика приватності, сторінка 404.
- Форма у великій панелі: валідація телефону, згода, підготовка поштового звернення. Автоматичне надсилання ще не підключене.
- Окремі телефон, WhatsApp, Viber, Telegram і email. Telegram username відсутній; кнопка показує чесне повідомлення з доступними альтернативами.
- Новий 5-секундний брендований вступ, окрема вертикальна мобільна композиція, пропуск, плавне завершення, вимкнення для reduced motion.
- Карусель шести робіт на головній, однакові пропорції карток, єдина система CTA та адаптація до ширини 320 px.
- Локальні шрифти Manrope, адаптивні WebP, соціальна обкладинка, favicon, manifest, sitemap, метадані та структуровані дані компанії.

## Контент і походження

Оригінальний `logo.jpg` збережений; сайт використовує очищену внутрішнім imagegen версію `logo-clean.png` без чорного фону. Фотоматеріали першої версії створені через Higgsfield; під час redesign статичні матеріали через Higgsfield не генерувалися. Розділ «Наші роботи» зберігає чесне позначення зображень як візуалізацій. Відсутня вигадана статистика.

Redesign: витрачено **45 із максимум 100 Higgsfield credits** на один фінальний intro. Детальні записи, джерела та стан роботи: [REDESIGN-WORKLOG.md](REDESIGN-WORKLOG.md). Не запускати старі скрипти генерацій для продовження redesign.

Десять текстових прикладів відгуків знаходяться в `app/src/slava/review-drafts.ts`. Вони не публікуються як справжні відгуки. Для публікації потрібні підтверджені клієнтські тексти.

Форма зберігає підготовлене звернення тільки у sessionStorage поточної сесії. Для наступного етапу потрібно додати серверний обробник та Telegram bot/chat ID як секрети сервера. Не розміщувати токен бота у клієнтському коді.

## Перевірка

`bun run typecheck`. Локальна інтерактивна перевірка: `bun x playwright install chromium`, потім `node check-site.mjs` при запущеному сервері. Скрипт перевіряє 12 сторінок у desktop/mobile, зображення, переповнення, форму, Telegram, фільтри, проєктний діалог та клавіатурний slider.

## Матеріали

`refs/` містить дизайн-референси. `media-jobs/` містить параметри та результати генерацій без облікових токенів. `tools/` містить інструменти підготовки матеріалів; повторна генерація витрачає кредити.
